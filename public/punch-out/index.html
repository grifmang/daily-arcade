Controller setup and controls

Standard pad: bottom face button (A / Cross) = right punch; right face button (B / Circle) = left punch. D-pad or left stick = face, block and dodge. Start / Menu = star or continue. Select / View = corner recovery. Top face button (Y / Triangle), or Start + Select together = pause.

While paused: Start resumes, left/right chooses opponent, Select restarts. On results: Start continues or starts a new career after the ending / game over. Release all controls after reconnect, reset or pause before pressing again. Other USB pads: remap all eight controls, including axis directions; Start + Select pauses. Mapping saves for this device in this browser. Click or press a key to enable sound if requested.
